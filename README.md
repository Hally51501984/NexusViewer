# NexusViewer
**超高速・軽量シームレスメディアビューア (Android 8.0+ 対応)**

## 概要
NexusViewer は、オープンソースギャラリーアプリ「Fossify Gallery」をベースに、徹底的な不要機能の削ぎ落とし（デブロート）と極限の起動高速化・操作性向上を追求した、Android 8.0（API 26）以上対応の軽量メディアビューアです。

外部ファイラー等から写真・動画を開いた瞬間から0遅延・シームレスに同フォルダ内のメディアを高速ブラウジングでき、反復練習や確認に最適な動画プレーヤー機能や、画素を一切劣化させない無変形画像編集ツールを備えています。

---

## 主な特徴と強み

### 1. 爆速起動 & ゼロ遅延レスポンス
- 外部ファイラー連携時のIntent処理を最適化。
- バックグラウンド処理や不要なサービスを完全排除し、タップから画面表示までの起動コストを極限まで低減。

### 2. 快適で直感的な操作体系（ジェスチャー）
- **左右端スワイプ（画面幅の左端25% / 右端25%）**:
  - 前後の写真・動画へシームレスにページめくり。動画再生中であってもスムーズに切り替え可能。
- **画面中央シーク（画面幅の中央50% 横スワイプ）**:
  - 指のスワイプ量に応じて直感的に再生位置をシーク（進む/戻る）。
- **縦スワイプ調整（明るさ & 音量）**:
  - **画面左半分**: 上下スワイプで画面の明るさを滑らかに調整。
  - **画面右半分**: 上下スワイプで音量を滑らかに調整。
- **中央長押し**:
  - 押している間、一時的に2.0倍速で高速再生。
- **動画切り替え時の音声制御**:
  - スワイプの瞬間や切り替え時に前動画の音声を即時カットし、音ズレや音声の残留・二重再生を防止。

### 3. ギタリスト・練習向けの動画リピート機能
- **「1曲リピート」機能**:
  - リピートトグル（Off / フォルダ巡回 / 1曲リピート）を搭載。
  - ギターのフレーズ練習や特定パートの反復確認に最適。

### 4. 無変形（ロスレス）画像編集
- ピクセルを変形・再エンコードすることなく、回転情報を付与する形式による可逆回転。
- トリミング、反転などの必須ツールのみを軽量に維持。

### 5. 徹底的なデブロート（不要機能削除）
- ごみ箱（Recycle Bin）、生体認証・アプリロック、壁紙設定、カメラ起動、過剰な設定項目など、ビューアの本質に不要な機能を完全削除。

## ビルド方法

Gentoo Linux 等の環境で、JDK 17 および Android SDK をセットアップした状態でビルド可能です。

```bash
# 環境変数の読み込み
source ./env.sh

# デバッグAPKのビルド
./gradlew assembleFossDebug
```

生成されるAPKファイル:
`app/build/outputs/apk/foss/debug/gallery-29-foss-debug.apk`
